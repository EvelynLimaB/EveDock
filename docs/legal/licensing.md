# EveDock Licensing Model

EveDock contains three distinct classes of work.

## Hardware

Hardware design source, including schematics, PCB source, and mechanical design, is intended to use the CERN Open Hardware Licence Version 2 - Strongly Reciprocal (CERN-OHL-S-2.0).

## Firmware and software

Firmware, configuration code, integration code, and other software are intended to use Apache License 2.0.

## Documentation

Documentation, diagrams, tables, test procedures, and explanatory text are intended to use Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).

## Release rule

A released artifact must clearly identify its applicable license. The repository should include the complete corresponding license text before claiming that the artifact is formally released under that license.

This file describes project intent; it is not a substitute for the complete license texts.
