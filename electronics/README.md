# Electronics

Electrical design workspace.

Planned layers:

- `power-path/` — source selection and ideal-diode/power mux.
- `protection/` — fusing, current limiting, reverse-polarity and fault protection.
- `12v-bus/` — distribution and connectors.
- `12v-to-19v/` — regulated laptop rail.
- `telemetry/` — voltage/current sensing.

No circuit in this directory is considered production-ready until it is accompanied by a validated schematic, component limits, and relevant test results.
